The current documents are:

- [`Planning Docs/Code_Review_and_Refactor_Plan_2026-09.md`](../../Planning%20Docs/Code_Review_and_Refactor_Plan_2026-09.md): the plan, its decisions and its progress.
- [`FAB_MARKETPLACE_READINESS.md`](../../FAB_MARKETPLACE_READINESS.md): the Fab readiness report.
- [`docs/ARCHITECTURE.md`](../ARCHITECTURE.md) and [`CONTRIBUTING.md`](../../CONTRIBUTING.md): how the plugins are built, and how to work on them.
- [`docs/USER_GUIDE.md`](../USER_GUIDE.md) and [`docs/EDITOR_TESTS.md`](../EDITOR_TESTS.md): how to use the plugins, and the checks that need a person in the editor.
